# Privacy

Iniva is designed to collect no personal data.

- No account, name, phone number, e-mail or location is requested.
- No cookies, local storage, analytics or third-party trackers are used.
- Questions are processed in the browser and are not sent to any server in retrieval mode.
- In optional LLM mode, the question is sent only to the open-source model endpoint configured by the operator (self-hosted); it must not be logged.
- Test mode keeps aggregate counts in memory only; the CSV export contains counts per topic, never question text.
- The future WhatsApp channel will be designed so that phone numbers are not stored or linked to questions.
